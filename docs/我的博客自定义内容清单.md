## 以后怎么辨认

- **你的照片、文章、动态、项目和相册内容**放在 `src/content/` 或 `public/` 的对应文件夹。
- **主题开关、链接、音乐、壁纸等设置**改 `src/config/` 里的配置。
- **主题组件和样式代码**位于 `src/components/`、`src/styles/`。除非明确要改变功能或外观，尽量先别改这些模板代码。
- 本清单记录的是当前已知的自定义项。以后添加新文章、相册或图片时，可以在此补记。
